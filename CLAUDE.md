# Switchboard — правила для Claude в цьому репозиторії

Локальний оркестратор для `claude` і `agy` (Antigravity): ліміти, роутинг, передача між агентами, задачі, чат. Загальний опис і команди — у `README.md`.

## Мова
- Спілкування з користувачем — **українською**.
- Коментарі в коді — **англійською**. Тексти інтерфейсу дашборду — українською.

## UI — тільки shadcn/ui (обов'язково)
- Дашборд (`apps/dashboard`) будується **виключно з компонентів shadcn/ui** (стиль `radix-vega`, `components.json`), Tailwind v4 і токенів теми з `src/styles/global.css` (CSS-змінні oklch). Кольори, типографіка, радіуси, відступи — як у shadcn; власного CSS і власних «кнопок/карток» не пишемо.
- Новий елемент UI: спершу `npx shadcn@latest add <компонент>` (з каталогу `apps/dashboard`), потім використовуємо його як є. Файли в `src/components/ui/` — це вендорний код shadcn: правимо їх лише в крайньому разі.
- Інші UI-бібліотеки (MUI, Chakra, Bootstrap тощо) і ручна верстка заміни компонентів — заборонені. Іконки — `lucide-react`.
- Нових семантичних кольорів (як `--success`, `--warning`) додаємо в `global.css` так, як описує документація shadcn (CSS-змінна + `@theme inline`), а не хардкодом hex.
- Статус завжди передаємо ще й текстом, а не лише кольором (a11y).
- Нотатка про запуск CLI: `npx shadcn@latest` викликає глобальний `pnpm`, який конфліктує зі сховищем pnpm 12 цього репо. Обхід: тимчасовий `pnpm`-shim у `PATH`, що виконує `npx -y pnpm@12.8.1 …`.

## Безпека (не порушувати)
- Агенти працюють лише в гілках `sb/*`; жодних merge у `main`, деплою, `--force`, `reset --hard`; `netlify.toml` не чіпаємо.
- Один акаунт на провайдера; секрети маскуємо в логах (`packages/core/mask.ts`); дашборд слухає лише `127.0.0.1`; недокументованих API немає.
- Shell для `agy` не вмикаємо.

## Робота
- Перед комітом: `pnpm typecheck`, `pnpm test`, для дашборду `pnpm --filter @switchboard/dashboard build`.
- Коміти — напряму в `main`, невеликі й осмислені.
- Залежності: `npx -y pnpm@12.8.1 add …` (політика `minimumReleaseAge` pnpm 12).
