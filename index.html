Claude hits the limit.
ChatGPT takes over.

A local switchboard for three AI coding agents: Claude Code, Antigravity and ChatGPT (Codex CLI). It reads what's left on every subscription, sends each task to whoever can take it, and hands the task over when a limit hits.

the core idea

Limits first. Agent second.

1
Read what's left

5-hour and weekly windows for every agent: available, low, reserve, exhausted.

2
Route by task type

research, ideas, copy, section, review, qa: each has its preferred order of agents.

3
Checkpoint on a limit

a wip commit plus a handoff note in PROGRESS.md: files, last output, reason.

4
Next agent continues

same sb/* branch, up to 2 handoffs, then it waits for you.

what's inside

3 agents, one dashboard.

Dashboard

shadcn/ui on 127.0.0.1: limits, tasks and chats across projects in one place.

Chat

several chats at once, switch agent and model mid-conversation, commit per answer.

Cross review

code is always reviewed by a different agent than the one who wrote it.

Attachments

screenshots, PDF, docx, xlsx, even video frames via ffmpeg.

Read-only parallel chats

sb chat --read-only --web for research next to a writing task.

API for Make

sb api: prompt in, answer out, Bearer token, read-only by default.

safety

Main changes only when you say so.

  • Agents work only in sb/* branches and never merge, push or deploy.
  • "Merge into main" is a button with a confirmation, fast-forward only.
  • Switchboard itself never runs git push or a deploy.
  • One account per provider, subscriptions, no API keys. Secrets are masked in logs.
install

Run it locally.

  • Node.js 20+ and pnpm (corepack enable)
  • claude and agy installed and signed in; codex optional (npm i -g @openai/codex, then codex login)
  • ffmpeg optional, for video attachments
git clone https://github.com/olexlebid/switchboard
cd switchboard
pnpm install
pnpm sb status            # shows each agent's limits
pnpm sb dashboard         # http://127.0.0.1:4321
pnpm sb project add ~/projects/my-site
pnpm sb init ~/projects/my-site
